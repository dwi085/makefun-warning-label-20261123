A make.fun entry for [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): a program that writes exactly one line of comedy — the safety warning label that should come printed on every human being — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes a single deterministic line (at most 160 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no file reads.
